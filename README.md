# CCC-backend-task-2

Blog API built using **Node.js, Express.js, and MongoDB**.


- User Signup & Login
- JWT-based Authentication
- User Profile Fetch & Update
- Logout
- Create Blog Post
- Get All Posts
- Get Single Post
- Update Post
- Delete Post
- Image Upload
- Tags and Timestamps

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Postman

## Run Project

```bash
npm install
npx nodemon server.js
